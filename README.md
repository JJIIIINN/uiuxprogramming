## 6주차: JavaScript 이벤트와 동적 UI

`주요 기능` 섹션을 탭 3개(물주기 알림 · 사진 진단 · 성장 일지)로 바꾸고, 탭마다 해당 기능을 직접 써 볼 수 있는 화면을 넣었습니다.

### 구현한 이벤트

| 이벤트 | 대상 | 동작 |
| --- | --- | --- |
| `click` | 주요 기능 탭 3개 | 누른 탭만 선택 상태로 바꾸고 해당 탭의 내용만 표시 |
| `click` | `오늘 물 줬어요` 버튼 | 오늘 날짜에 물주기 간격을 더해 다음 물주기 날짜 안내 |
| `click` | `일지에 기록하기` 버튼 | 메모를 오늘 날짜와 함께 일지 맨 위에 추가 |
| `change` | 식물 종류 · 놓아둔 자리 선택창 | 식물별 기본 간격 × 자리별 비율로 물주기 간격 계산 |
| `change` | 잎 상태 선택(라디오 버튼) | 고른 증상에 맞는 진단 결과 표시 |
| `input` | 성장 일지 메모 입력창 | 글자 수를 실시간으로 표시하고 60자 초과 여부 확인 |
| `input` | 알림 신청 폼 입력창 | 오류 표시와 버튼 상태 초기화 (5주차) |
| `submit` | 알림 신청 폼 | 입력값을 확인하고 결과 안내 (5주차) |

### 사용자 행동에 따른 화면 변화

| 사용자 행동 | 문구 | 스타일 | 버튼 상태 |
| --- | --- | --- | --- |
| 탭 클릭 | 선택한 기능의 설명과 체험 화면만 표시 | 선택한 탭은 흰 배경 · 파란 굵은 글씨 | 선택한 탭만 `aria-selected="true"` |
| 식물 종류나 자리 중 하나만 선택 | "식물 종류와 놓아둔 자리를 모두 골라 주세요." | 회색 안내 | `오늘 물 줬어요` 비활성 |
| 식물 종류와 자리 모두 선택 | "6일마다 물을 주면 좋아요. …" | 회색 안내 | `오늘 물 줬어요` 활성 |
| `오늘 물 줬어요` 클릭 | "기록했어요! 다음 물주기는 10월 18일(일)이에요." | 파란 성공 안내 | `물주기 완료`로 바뀌고 비활성 |
| 물주기 완료 후 선택을 다시 바꿈 | 새 간격 안내 | 회색 안내 | `오늘 물 줬어요`로 돌아오고 활성 |
| 잎 상태 선택 | 증상별 해야 할 일 안내 | 고른 칩은 파란 테두리, 결과는 건강=파랑 · 건조/빛 부족=주황 · 과습/해충=빨강 | - |
| 메모가 비었거나 공백만 입력 | "0 / 60자" | 회색 글자 수 | `일지에 기록하기` 비활성 |
| 메모 1~60자 입력 | "17 / 60자"처럼 실시간 표시 | 회색 글자 수 | `일지에 기록하기` 활성 |
| 메모 60자 초과 | "64 / 60자", "60자 이내로 줄여 주세요." | 글자 수 · 입력창 테두리 · 안내 빨강 | `일지에 기록하기` 비활성 |
| `일지에 기록하기` 클릭 | 일지 맨 위에 새 항목 추가, "오늘의 메모를 성장 일지에 남겼어요." | 파란 성공 안내 | 입력창을 비우고 비활성 |
| 알림 신청 (5주차) | 빈 칸 · 이메일 형식 오류 / 신청 완료 안내 | 빨간 오류 · 파란 성공, 오류 입력칸 빨간 테두리 | `신청 완료`로 바뀌고 비활성 |

### 테스트 결과

Chrome에서 화면 너비 1100px · 768px · 390px로 페이지를 열고, 위 표의 행동을 실제로 클릭 · 입력 · 선택해 문구 · 스타일 · 버튼 상태가 바뀌는지 확인했습니다. 390px은 모바일 화면(터치)으로 테스트했습니다. 단계마다 가로 스크롤이 생기거나 화면 밖으로 잘리는 요소가 있는지도 검사했습니다.

| 확인 항목 | 1100px | 768px | 390px |
| --- | :---: | :---: | :---: |
| 가로 스크롤 · 잘린 요소 없음 | 통과 | 통과 | 통과 |
| 탭 전환: 선택 표시, 해당 콘텐츠만 표시 | 통과 | 통과 | 통과 |
| 물주기 간격 계산 (`change`) → 물 준 날 기록 (`click`) | 통과 | 통과 | 통과 |
| 잎 상태 진단 (`change`) | 통과 | 통과 | 통과 |
| 메모 글자 수 · 60자 초과 · 공백만 입력 (`input`) | 통과 | 통과 | 통과 |
| 일지 기록 추가 (`click`) | 통과 | 통과 | 통과 |
| 알림 신청 폼 (`submit`, `input`) | 통과 | 통과 | 통과 |
| 콘솔 JavaScript 오류 | 없음 | 없음 | 없음 |

- 1100px: 선택창 2개와 버튼이 한 줄에 놓이고, 잎 상태 칩 5개가 한 줄에 들어갑니다.
- 768px 이하: 선택창 · 입력창 · 버튼이 세로로 쌓이고 버튼이 전체 너비로 늘어납니다. 탭 3개는 화면 너비를 3등분합니다.
- 390px: 잎 상태 칩이 여러 줄로 내려가고, 일지 항목은 날짜 아래에 메모가 표시됩니다. 긴 문장은 단어 단위로 줄바꿈됩니다.
